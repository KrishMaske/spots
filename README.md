# Spots

Spots is a mobile-first collaborative trip planner. Groups plan trips together,
get recommendations tailored to everyone invited, and turn completed trips into
shared albums, collaborative playlists, and a social travel feed.

## Current Scaffold

Verified against disk on 2026-06-29. The current repo is a lightweight
polyglot scaffold, not the older `cmd/`, `internal/`, `backend/reco/`, or
Taskfile-based layout described in earlier plans.

| Area | Current state |
|---|---|
| [backend/](backend/README.md) | Go monolith scaffold in `backend/golang/`, Python reco service in `backend/python/`, local Postgres/MinIO compose in `backend/deploy/local/`. |
| [mobile/](mobile/README.md) | Expo (managed) + React Native + TypeScript app. Runnable auth flow (Landing/Login/Register/Confirm) wired to the Go edge's `/v1/auth/*`. |
| [frontend/](frontend/README.md) | Empty placeholder for a future web client. No framework selected. |
| [docs/](docs/current-scaffold.md) | Current scaffold map, completed records, plans, and reports. |

## Quick Start

Python reco is the only service verified runnable in the current scaffold:

```powershell
cd backend\python
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

Then verify:

```powershell
Invoke-RestMethod http://localhost:8081/health
```

The intended Go command is:

```powershell
cd backend
go run ./golang
```

The earlier `backend/go/...` vs `backend/golang/...` import-path mismatch is
resolved; all files import `github.com/krishm/spots/backend/golang/...` and
`go test ./...` passes. Do not document or assume `backend/go`, `backend/cmd`,
or `backend/internal` as current paths.

Local infra can be started directly with Docker Compose:

```powershell
docker compose -f backend/deploy/local/docker-compose.yml up -d
docker compose -f backend/deploy/local/docker-compose.yml ps
docker compose -f backend/deploy/local/docker-compose.yml down
```

There is currently no root `Taskfile.yml`, no `backend/Taskfile.yml`, and no
`backend/dev.ps1`.

## Tech Stack

- Backend: Go, Python/FastAPI
- Mobile: React Native + TypeScript (Expo managed, SDK 54) — see `mobile/README.md`
- Infra: PostgreSQL + pgvector, MinIO; Redis is not in compose yet
- Contracts: hand-authored Go OpenAPI at `backend/golang/routes/openapi/openapi.json`; Python FastAPI OpenAPI is generated by FastAPI
